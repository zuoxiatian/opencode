# Downloads

Place the packaged LongwiseTechAgent release artifacts in this directory when deploying the official site with the default download base.

The site links to files by name, for example:

- `LongwiseTechAgent-1.0.0-win-x64.zip`
- `LongwiseTechAgent-1.0.0-mac-arm64.dmg`
- `LongwiseTechAgent-1.0.0-mac-x64.zip`

Set `VITE_DOWNLOAD_BASE_URL` during build if the artifacts are hosted on a CDN or release server.
